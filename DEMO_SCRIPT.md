# Gemini Screen Navigator - Demo Video Script

**Duration**: 3-4 minutes
**Format**: Screen recording with voiceover
**Resolution**: 1920x1080 (Full HD)

---

## Scene 1: Introduction (0:00 - 0:30)

**Visual**: Show the Gemini Navigator homepage with Brutalist design

**Voiceover**:
"Welcome to Gemini Screen Navigator, an AI-powered desktop automation agent that uses Google's Gemini Pro Vision API to autonomously execute complex tasks on your desktop. Today, we'll demonstrate how this intelligent system perceives, plans, acts, and verifies actions in real-time."

**Actions**:
- Show the main interface with the red divider line
- Highlight the task input form
- Display the "START NEW TASK" heading

---

## Scene 2: Task Input (0:30 - 1:00)

**Visual**: Demonstrate entering a task goal

**Voiceover**:
"Let's start by entering a task goal. I'll ask the agent to perform a simple web automation task: 'Open Google Chrome and search for Gemini AI technology, then take a screenshot of the results.'"

**Actions**:
1. Click on the Task Goal input field
2. Type: "Open Google Chrome and search for 'Gemini AI technology', then take a screenshot of the results"
3. Click on Additional Context field
4. Type: "Use the default search engine, take screenshot after results load"
5. Show the START TASK button

---

## Scene 3: Task Execution (1:00 - 2:30)

**Visual**: Show the Execution Dashboard with live progress

**Voiceover**:
"Once we click START TASK, the agent begins its Perceive-Plan-Act-Verify loop. First, it captures the current desktop state. Then, it sends the screenshot to Gemini for analysis. Gemini understands the UI and generates a step-by-step action plan. The agent then executes each action, captures the result, and verifies success."

**Actions**:
1. Click START TASK button
2. Show the progress bar moving from 0% to 100%
3. Display the execution log in real-time:
   - "Step 1: Perceive - Capturing desktop screenshot..."
   - "Step 2: Plan - Analyzing with Gemini Pro Vision..."
   - "Step 3: Gemini Response - Detected Chrome browser, search bar visible"
   - "Step 4: Act - Clicking on Chrome icon..."
   - "Step 5: Verify - Comparing before/after screenshots..."
   - "Step 6: Success - Chrome opened successfully"
   - "Step 7: Act - Typing search query..."
   - "Step 8: Verify - Search results loaded"
   - "Step 9: Act - Taking screenshot..."
   - "Step 10: Complete - Task finished successfully"

4. Show the step counter (e.g., "Step 5 of 10")
5. Display the current action being executed

---

## Scene 4: Screenshot Gallery (2:30 - 3:15)

**Visual**: Show the Before/After screenshot gallery

**Voiceover**:
"As the agent executes each step, it captures before and after screenshots. This provides complete evidence of what happened and allows us to verify that each action succeeded. Let's look at the screenshot gallery showing the progression of our task."

**Actions**:
1. Scroll through the screenshot gallery
2. Show 3-4 before/after pairs:
   - Desktop before → Chrome opened
   - Chrome empty → Search bar focused
   - Search bar empty → Search query typed
   - Results loading → Results displayed
3. Highlight the timestamps on each screenshot
4. Show the success checkmarks next to each step

   - Screenshots embedded in the report
   - Timestamps and durations

4. Show the download button
5. Display the Cloud Storage URL where the report is stored

## Technical Specifications

### Recording Settings
- **Resolution**: 1920x1080 (Full HD)
- **Frame Rate**: 30 FPS
- **Bitrate**: 5000 kbps
- **Audio**: 128 kbps, 48 kHz

### Editing Requirements
- Add title card at the beginning (2 seconds)
- Add background music (subtle, non-intrusive)
- Add text overlays for key points
- Add transitions between scenes
- Add captions/subtitles (optional but recommended)
- Fade to black at the end (1 second)

### Audio
- Clear, professional voiceover
- Speak at a moderate pace (120-150 words per minute)
- Use a lavalier microphone or high-quality USB microphone
- Add subtle background music (royalty-free)
- Ensure audio levels are consistent throughout

### Recommended Tools
- **Recording**: OBS Studio (free), ScreenFlow (Mac), Camtasia
- **Editing**: DaVinci Resolve (free), Adobe Premiere Pro, Final Cut Pro
- **Audio**: Audacity (free), Adobe Audition

## Tips for Recording

1. **Test First**: Record a test run to ensure everything works

4. **Zoom In**: Zoom into text-heavy areas for readability
5. **Be Concise**: Stay within the 4-minute limit
6. **Professional**: Use a clean desktop with no distracting elements
7. **Backup**: Record in multiple formats for safety
