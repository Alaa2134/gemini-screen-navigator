# Devpost Submission Guide - Gemini Screen Navigator

This guide walks you through submitting your project to the Google Gemini Live Agent Challenge on Devpost.

## Challenge Details

| Field | Value |
|-------|-------|
| **Challenge** | Google Gemini Live Agent Challenge |
| **Website** | https://geminiliveagentchallenge.devpost.com/ |
| **Deadline** | March 16, 2026 |
| **Prize** | $25,000 USD (Cash) |
| **Category** | Screen Navigation & Desktop Automation Agent |

## Pre-Submission Checklist

Before submitting, ensure you have:

- [x] GitHub repository created and public
- [x] All code pushed to GitHub
- [x] README.md with setup instructions
- [x] ARCHITECTURE.md with system design
- [x] PROJECT_DESCRIPTION.md (1500+ words)
- [x] architecture.png (diagram)
- [x] DEMO_SCRIPT.md (video script)
- [x] deploy.py (deployment script)
- [ ] Demo video recorded and uploaded to YouTube
- [ ] Google Cloud Run deployment completed
- [ ] Service URL tested and working

## Step-by-Step Submission

### Step 1: Create Devpost Account
1. Go to https://devpost.com/
2. Click "Sign Up"
3. Create account with email
4. Verify email address

### Step 2: Navigate to Challenge
1. Go to https://geminiliveagentchallenge.devpost.com/
2. Click "Submit a Project"

### Step 3: Fill Project Information

**Project Title**:
```
Gemini Screen Navigator
```

**Tagline**:
```
AI-Powered Desktop Automation Agent Using Google Gemini Pro Vision
```

**Category**: Screen Navigation & Desktop Automation Agent

**Description**: Copy from PROJECT_DESCRIPTION.md (1500+ words)

**Video**: Upload MP4 or paste YouTube link

**GitHub Link**:
```
https://github.com/Alaa2134/gemini-screen-navigator
```

**Deployment Link**:
```
https://gemini-screen-navigator-[HASH].run.app
```

### Step 4: Upload Additional Files
- architecture.png
- DEPLOYMENT.md
- QUICK_START.md
- FAQ.md

### Step 5: Review & Submit
1. Review all information
2. Verify links work
3. Click "Submit Project"
4. Save confirmation number
